# RefCanvas 清理迭代:删除屎山代码 + 精简无用 UI + 拆分巨石组件

## 基线与验证门

- **Phase 0**:先跑 `pnpm check`(repo-check + lint + typecheck + test)确认绿色基线。
- 每个 Phase 结束后跑 `pnpm check`,全部完成后跑 `pnpm check:release`(含 performance/capacity/package/runtime 冒烟)。
- 每个 Phase 一个 conventional commit(`refactor:` / `chore:`)。
- 架构测试硬约束(全程遵守):`layers.test.ts` 钉死了 BoardCanvas 必须保留的 7 个 `features/board/*` + 4 个 controllers 导入字符串、DirectoryAssetPanel 必须保留的 4 个 `features/directory/*` + `DirectoryBatchToolbar` 导入;BoardCanvas < 6500 行(当前 6406,只剩 94 行余量,拆分正好创造余量);`title=` 基线只减不增(搬走的 JSX 顺带把 `title=` 换成 `aria-label` 并下调基线);渲染层禁用原生 `<select>`(统一用 `SelectMenu`);测试从单石文件导入 `DirectoryCard`/`directoryThumbnailSource`,搬移后须 re-export。
