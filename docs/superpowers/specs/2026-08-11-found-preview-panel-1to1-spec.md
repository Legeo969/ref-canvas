# Found 右侧预览面板 1:1 复刻规格

日期：2026-08-11
依据：`found-analysis/` 动态 UI 树几何 + 截图像素取色 + IDA 提取 QML 源码三重证据交叉验证。

## 0. 证据等级

| 等级 | 来源 | 用途 |
|---|---|---|
| A（权威） | QML 源码字符串（extracted-ui）+ 像素取色（System.Drawing 采样） | 颜色、布局常量 |
| B（实测） | UI Automation 树（08-*/06-svg preview-tree.json） | 控件坐标、尺寸、类型 |

所有色值已用 A 级证据校准。UI 树坐标为窗口客户区坐标（窗口 1692x900，右栏 x≥850）。

## 4. 画布区行为

- 画布叠加（左上角，白 12-16px 无衬线）：视频 `FRAME 024`、序列 `SEQUENCE 0008`。
- 图片/视频：fit 缩放；透明素材棋盘格背景（可切换）。
- 3D：深蓝紫渐变视口，实体着色，鼠标拖拽旋转；Camera(5) 面板切换预设视图。
- 取色器：预览画面取色（部分验证）。
- 颜色标签：图片预览右上色块按钮（A 级：thumb 缩略图与色板）。
- 沉浸预览：Enter 进入，Esc 退出。
- 删除等操作全屏 toast 提示（`toast.qml`）。

## 5. AI 设计总监面板（obs-4 + 02/15 截图）

- 空态：虚线边框上传区（#555555 虚线、圆角 8px）居中机器人插画 + 「拖放或右键粘贴原始设计」。
- 输入态（自顶向下）：
  1. 原图预览区（35%，深色，顶部 10px 灰色文件名行）
  2. 文本域（35-40%，无边框，placeholder「输入对原图的设计反馈，支持粘贴参考图或聊天记录截图 (0/6)」，右下拖拽抓手）
  3. `+` 附件按钮（40x40，圆角 6px，#3A3A3A）
  4. 底部操作栏（40px，#222222，顶部分隔线）：`需要较大改动` toggle + 灯泡提示(金色 #D4A843) + `- 2 张 +` 计数器 + `专业修改` 主按钮（80x30，深灰底 #3A3A3A-#444444，圆角 4-6px）
- 分隔线体系：1px `#3A3A3A`；虚线 #555555。

## 6. 空态（02-main-window）

- 几何插画（三角播放 + 圆球 + 倾斜板，单色 #555-#666）+「请在浏览区选择资产」（#666666，14px，居中）。

## 8. 实现验收标准

1. 右栏显示 Found 式 Tab（预览/AI 设计总监），点击素材右栏即时预览（无需浮层）。
2. 8 类型（图片/SVG/GIF/视频/音频/序列/PDF/3D）预览画布 + 工具条与规格一致（色值/布局/控件语义）。
3. 进度条/时间码/循环/FPS 行为对齐；序列绿色、视频蓝色。
4. SVG Layers 折叠面板、3D Camera(5)、PDF 白纸、空态插画+文案、AI 面板四区结构。
5. 与规格色板一致性：像素级抽查（#242424/#2E2E2E/#0085FF/#59D165）。
