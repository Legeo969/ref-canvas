# RefCanvas 0.37.1

- Release date: 2026-08-03
- Platform: Windows x64
- Signing: unsigned

## Highlights

- Fixed the `EINVAL lstat 'C:\DumpStack.log.tmp'` main-process crash when browsing a Windows drive root.
- Separated directory paging from directory observation. The observer uses a non-recursive native watcher and falls back to a five-second `mtime` poll after watcher creation/runtime errors.
- Added revision-safe directory indexing, bounded import enumeration with 512-item ACK batches, 12 concurrent file reads, 256-record database transactions, and progress capped at 10 Hz.
- Persisted base asset records before asynchronous metadata enrichment. Cancelled or failed enrichment no longer rolls back imported records and can resume from `pending` state.
- Added 200-record asset windows with at most 12 resident pages, batched tag/collection hydration, count-free follow-up windows, and lightweight thumbnail source lookup.
- Upgraded the database to schema v13 with metadata status/error timestamps and stable lifecycle/sort indexes.
- Split main persistence into migration, asset, collection, board, and settings repositories. Split library task ownership into import, metadata, and watch/reconcile services.
- Split renderer state into library, directory, board, and preferences slices. Moved components outside the app composition root and extracted drawing, history, selection, and viewport controllers while preserving a single Fabric lifecycle owner.

## Repository And QA

- Reorganized source, workers, tests, scripts, documentation, and application assets under explicit ownership boundaries.
- Archived 8,091 historical/generated files (7,920,259,214 bytes) with a SHA-256 manifest at `D:\AiWork\ref-canvas-archive\pre-0.37.1-2026-08-03`.
- Added repository hygiene, architecture, performance, capacity, packaged runtime, and Windows release gates.
- Release gate passed with 63 test files, 348 tests, 13 architecture assertions, 5 performance scenarios, and 2 capacity scenarios.
- The 500,000-entry directory and 500,000-asset first/deep/hydrated window gates passed their P95 <=250 ms limits.
- Packaged runtime run `2026-08-03T11-41-52-002Z-14124` passed fresh-profile root browsing and schema 12→13 migration with schema version 13.
