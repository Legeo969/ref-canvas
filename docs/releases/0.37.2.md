# RefCanvas 0.37.2

- Release date: 2026-08-03
- Platform: Windows x64
- Signing: unsigned

## Fixes

- Restored the Windows notification-area icon after the asset directory split.
- Made “在新窗口打开白板” create and focus the independent board window for the current board.
- Prevented shutdown-time window state reads and writes after the database connection closes.
- Runtime smoke now verifies independent board-window creation and fails on packaged-app shutdown timeouts.
- Fixed middle-button board panning in Fabric drawing mode, including browser autoscroll suppression and focus-loss cleanup.
- Fixed the asset grid's initial two-column layout after importing into an empty library.
- Fixed left-side folder actions being clipped and made the board context-menu grid action stateful.
- Made “在素材库中定位” switch to Library, clear excluding filters, and select the requested asset.
- Matched image and group transform controls to the reference style with eight blue circular resize handles, axis-specific edge scaling, and outside-corner rotation cursors.
