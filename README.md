# RefCanvas

当前版本：0.37.1

Windows-first、纯本地的视觉素材库与无限参考白板。

## 当前能力

- 支持 linked 引用导入和 managed 托管复制；新建 Library 默认 linked（保留文件原位），需要复制进库时在设置中选择"复制到资料库"。
- Found 式本地目录浏览：不导入即可浏览磁盘树，使用时按需 materialize 建立链接索引；`refbrowse://` 会话 token 预览，路径永不出现在 URL。
- 目录树一键导入：目录模式头部或文件夹卡右键"导入此目录到素材库"，按原目录层级自动重建嵌套文件夹；也可拖入侧栏文件夹指定落点，或选择"仅导入文件不建文件夹"。
- 目录浏览支持前进/后退与逐级可点击路径面包屑；资料库文件夹视图提供"全部素材 › 父 › 当前"面包屑逐级跳转。
- 目录卡片可拖入侧栏文件夹：文件按需入库并加入目标文件夹，文件夹按层级导入到目标文件夹下。
- 搜索即时预览与命中高亮：输入时下拉建议（文件夹/标签/素材，带缩略图与高亮名称，↑↓+Enter 键盘操作）；素材卡标题、目录条目名称与详情路径高亮命中词。
- 目录模式即时预览：单击选中卡片（Ctrl 增选、Shift 范围、Ctrl+A 全选文件），Space 打开预览浮层（图片/占位、←→ 循环浏览、打开/定位/复制路径/入库/入夹/标签/回收站）。
- 目录模式批量操作：批量工具栏支持加入素材库、添加到文件夹、设置标签、复制路径、移入回收站。
- SQLite + FTS5 素材索引、稳定游标分页、虚拟列表、组合筛选、排序、Smart Folder 与 `#标签` 搜索。
- 单选、范围选择和“全部筛选结果”批量操作；支持标签、集合、收藏、评分与颜色标签。
- 素材网格支持方向键、Home/End、PageUp/PageDown 浏览，Shift 扩展范围选择，Space 打开或关闭快速预览，`F` 收藏，`0–5` 评分；虚拟网格会自动跟随当前项。
- 素材卡右键菜单支持快速预览、资源管理器定位、批量收藏、完整路径文件夹搜索、任意文件夹加入/移出和安全移入回收站。
- 素材卡支持普通拖动到集合/白板，以及 `Alt+拖动` 将最多 500 个已选源文件原生拖到资源管理器、Photoshop、Blender 等外部程序。
- 后台导入任务提供进度、取消和失败报告；图片和系统媒体缩略图使用带文件指纹失效的可重建本地缓存。
- 监控素材文件夹，可查看、定位或停止监控；文件移动后支持手动定位或按文件指纹搜索修复。
- 应用托管回收站会安全移动源文件，支持不覆盖恢复和手动永久清空。
- 重复项先使用快速指纹发现候选，再用完整 SHA-256 校验；合并时同步标签、集合和白板引用。
- 图片/视频/音频/PDF 详情预览、Three.js 3D 预览与 Windows 系统缩略图回退。
- 图片支持归一化坐标空间评论：点选位置新增、编辑、重新定位和删除，标注内容可被中文素材搜索直接命中。
- 内置离线 FFprobe，自动提取视频/音频时长和视频尺寸；支持文件变化失效、旧素材批量重建与取消。
- 高级筛选支持宽高、文件大小、媒体时长、文件格式、画面方向、导入/修改时间与视觉主色组合，并随导航状态和 Smart Folder 持久化。
- `BoardDocumentV3` 无限白板支持独立背景与网格、吸附、对齐、分布、锁定、组合、蒙版、透明度、图层、跨白板复制、富文本便签和 3D 代理预览。
- 白板图片支持 Space/双击单图聚焦、左右循环浏览、原视口恢复，以及可调 3/5/10 秒的本地幻灯片。
- 白板绘图支持自由画笔、直线、矩形和圆形，提供颜色、1–24px 粗细、实线/虚线设置；Shift 可约束角度、正方形和正圆。
- 图层支持稳定父子关系：拖放建立/解除父级与重排层级，父级移动、缩放和旋转会同步变换全部子孙对象，并阻止循环引用。
- `Ctrl+Shift+P` 中文命令面板可搜索全部白板操作、查看当前快捷键并保留最近命令；支持中文、分组和英文别名检索。
- 白板触发命令快捷键可在命令面板内重绑、清除或恢复默认值；冲突与全应用保留键会在保存前明确拦截。
- Tab 专注编辑模式与 F11 无界面全屏展示模式互相独立；F11、Esc 或屏幕内按钮均可可靠退出展示。
- 多白板切换；PNG 与 versioned JSON 导出。
- 对象检查器：选中对象后按数值编辑位置 X/Y、宽/高（换算缩放）、旋转与不透明度，Enter/失焦提交进入撤销与持久化；工具栏"更多"与命令面板均可开关。
- 按选区导出 PNG：只导出选中对象的包围盒（无选区时导出全部），命令面板"导出选中对象 PNG"或工具栏"更多"菜单触发。
- 3D 预览相机写回：OrbitControls 拖动结束（含阻尼收敛与浮层关闭）把相机位置/目标写回 3D 卡片 `modelView`，撤销可回退，再次打开按文档保存的视角恢复。
- 白板 GIF 动画对象：GIF 素材进白板后按帧循环播放（ImageDecoder 本地解码，不依赖网络），右键"播放/暂停 GIF"切换，播放状态随文档保存恢复；帧画布不落盘，文档保持轻量。
- 多窗口白板：主窗口标题栏"在新窗口打开"，白板在独立窗口专注编辑（同一白板只允许一个窗口，重复打开自动聚焦；窗口内切换白板会转到对应窗口）；对话框、置顶/演示模式按窗口作用域生效。
- 白板引用索引、引用定位、项目收集目录和素材路径迁移。
- 每日/迁移前自动备份、手动备份、完整性校验恢复和诊断信息导出。
- 剪贴板图片采集、按需区域截图并自动入库。
- 深色四区工作台、专注白板模式、窗口置顶、单实例、窗口与素材导航状态恢复及可选全局快捷键。

所有素材、索引与白板数据均保存在本机；全局快捷键默认关闭。浏览器扩展、云同步、账户和在线更新服务不在当前版本范围内。

## 数据安全

- linked 导入不会复制或修改源文件；managed 导入会把经过完整 hash 校验的副本保存到当前 Library。
- “移入回收站”会将源文件移动到 RefCanvas 数据目录；只有二次确认的“永久删除”会清除文件。
- 自动备份只包含数据库、设置和白板，不包含源素材或回收站文件。
- 卸载程序默认保留用户数据库。

## 快捷键

- `Ctrl+K`：聚焦素材搜索
- `Ctrl+Shift+P`：打开白板命令面板
- `Ctrl+A`：选择当前全部筛选结果（素材面板）
- `Alt+拖动素材`：将选中素材的源文件拖到外部程序
- `Ctrl+C / Ctrl+V`：跨白板复制粘贴对象
- `Ctrl+G / Ctrl+Shift+G`：组合/取消组合
- `Ctrl+Z / Ctrl+Y`：撤销/重做
- `Space`：聚焦选中图片/返回原视图；聚焦时 `←/→` 浏览前后图片
- `Tab`：专注白板
- 可选全局快捷键：`Ctrl+Shift+C` 捕获剪贴板，`Ctrl+Shift+R` 区域截图
- 透明穿透模式紧急退出：`Ctrl+Alt+Shift+R`

## 开发

```powershell
pnpm install
pnpm check
pnpm start
pnpm check:release
```

`pnpm check` 是日常变更门禁（仓库卫生、ESLint、类型检查、架构边界、单元与集成测试）；
`pnpm check:release` 额外执行性能 smoke 与 Electron 打包。该门禁通过
[`.github/workflows/check.yml`](.github/workflows/check.yml) 在每次推送与 PR 上强制执行，
不再依赖本地自觉。架构边界和后续拆分计划见
[`docs/architecture/overview.md`](docs/architecture/overview.md)。

执行完整发布门禁并生成 Windows 安装程序、ZIP、版本与 SHA-256 manifest：

```powershell
pnpm release:windows
```

发布文件写入 `D:\AiWork\ref-canvas-releases\<version>`，仓库只保留 release notes 和 manifest。

Windows 代码签名可通过以下环境变量启用；未设置时生成 unsigned 本地安装包：

```powershell
$env:REFCANVAS_CERTIFICATE_FILE="C:\path\certificate.pfx"
$env:REFCANVAS_CERTIFICATE_PASSWORD="..."
pnpm release:windows
```
